# Review comment labels

Prefix review comments with `required`, `question`, or `suggestion` so the author can understand their importance and respond appropriately.

Use `required` for important changes that should be addressed before the work is ready. Use `question` when something is unclear and needs discussion. Use `suggestion` for useful improvements that could make the change better.

Keep comments specific and constructive. Explain the concern and provide enough context for the author to act on it. Apply the labels consistently throughout the review so minor feedback does not distract from the main issues.
