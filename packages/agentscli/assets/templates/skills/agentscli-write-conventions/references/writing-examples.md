# Writing examples

This library compares 16 complete convention drafts with corrected versions. The agreements are fictional teaching contexts, not agentscli policies, client defaults, templates, or resources to install as project conventions. Each case establishes its hypothetical agreements in the analysis; missing evidence in a real project must be resolved from the request and verified facts, not invented from these examples.

## Find a writing problem

Choose cases by the reader's unresolved decision, then read the analysis and both complete files. A case can help with a different subject; transfer the concept without copying its technology, names, agreements, or document structure. Read additional cases when they address another difficulty in the draft; there is no requirement to reproduce the library in a batch.

## Use the information gained

Start with a concrete doubt, choose an example that answers it, then choose a presentation that exposes the answer. Apply the draft to a plausible task: can the reader distinguish compliant work from a reasonable alternative using the document alone? An author's claim that a technical rule is already clear does not demonstrate that application.

The analyses explain why their particular presentations help. Their comparison structure is teaching material, not an outline for final conventions. Repeating a useful presentation can be correct; variety alone proves nothing. Do not impose format quotas, minimum length, mandatory snippets, or a ban on tables. Keep an addition only when it supplies relevant context or resolves a decision that was previously ambiguous. Keep a short agreement short when it already does that work.
