# Writing examples

This library contains 16 before/after case studies with complete convention files. A correction may produce multiple conventions when the draft mixes independent decisions; read every resulting file linked by that case. The agreements are fictional teaching contexts, not agentscli policies, client defaults, templates, or resources to install as project conventions. Each case establishes its hypothetical agreements in the analysis; missing evidence in a real project must be resolved from the request and verified facts, not invented from these examples.

## Find a writing problem

Choose cases by the reader's unresolved decision, then read the analysis, complete original, and all resulting convention files. A case can help with a different subject; transfer the concept without copying its technology, names, agreements, or document structure. Read additional cases when they address another difficulty in the draft; there is no requirement to reproduce the library in a batch.

## Use the information gained

Start with a concrete doubt, choose an example that answers it, then choose a presentation that exposes the answer. Apply the draft to a plausible task: can the reader distinguish compliant work from a reasonable alternative using the document alone? An author's claim that a technical rule is already clear does not demonstrate that application.

The analyses explain why their particular presentations help. Their comparison structure is teaching material, not an outline for final conventions. Repeating useful before/after examples is appropriate when they teach distinct decisions. For non-obvious boundaries, exceptions, precedence, and transformations, supply concrete situations, compliant outcomes, inadequate alternatives, and explanations. Do not use brevity as a reason to omit that teaching evidence. Avoid format quotas, minimum length, or a ban on tables. A simple unambiguous literal agreement can remain short. Case 02 separates destination from wording; case 09 separates fixture independence from clocks; case 08 keeps an exception with its rule; case 12 separates independent agreements and an operational procedure.
