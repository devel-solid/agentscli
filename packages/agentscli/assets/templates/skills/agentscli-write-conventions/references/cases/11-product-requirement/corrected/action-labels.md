trigger: Read when writing labels for buttons that commit an action.

# Action labels

Name the action committed by a button with a verb and its object. The label describes what happens when that button is selected, rather than the feature the user is visiting.

- `Create booking` fits a button that submits a new booking. `Booking` names the subject without identifying the action.
- `Cancel booking` fits a button that confirms cancellation. `Continue` leaves the consequence to surrounding text.

If a feature has a confirmation screen, its committing button names the same action and object as the action being confirmed. This agreement determines the wording; the feature specification determines whether confirmation is required and when the action is available.
