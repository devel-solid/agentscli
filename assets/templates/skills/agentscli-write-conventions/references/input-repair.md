# Repair invalid convention inputs

The checker diagnoses inputs and never repairs them. A failed baseline permits analysis. The authoring agent may apply only the mechanical repair covered by the active request or approved structural plan, then reruns strict validation before ordinary prose work. These examples establish their hypothetical agreements; they do not grant repair authorization.

## Rename an incorrectly named file

The request approves preserving a test-focus agreement while correcting its filename. Before, `wrong-name.md` contains:

```markdown
---
trigger: Read when defining test cases.
---

# Test focus

Test one observable behavior at a time. A test for invalid-name rejection does
not also assert successful file creation; several assertions about the same
rejection can remain together.
```

Strict preflight reports SOURCE_FILENAME and the expected `test-focus.md` basename. After the authoring agent confirms that destination is free, the complete `test-focus.md` is:

```markdown
---
trigger: Read when defining test cases.
---

# Test focus

Test one observable behavior at a time. A test for invalid-name rejection does
not also assert successful file creation; several assertions about the same
rejection can remain together.
```

Only the path changes. Preserve the original bytes, including its line endings. Rerun preflight; only a successful result allows the separately requested prose revision. Changing the H1 to Wrong name would hide the filename defect by changing the agreement's identity. If `test-focus.md` already exists, report the collision and reconcile it through an approved plan rather than overwriting it.

## Restore a known trigger without inventing policy

The fictional team has approved the trigger `Read when naming text snapshot fixture files.` for this existing agreement. Before, `snapshot-extensions.md` lacks metadata:

```markdown
# Snapshot extensions

Give text snapshot fixture files the lowercase .snap extension.
```

After the authoring agent applies the approved metadata repair:

```markdown
---
trigger: Read when naming text snapshot fixture files.
---

# Snapshot extensions

Give text snapshot fixture files the lowercase .snap extension.
```

Validate again before expanding or reorganizing the convention. If the reading condition was not established, report the missing decision and propose it; a repair request does not authorize fabricating one. An audit-only request stops at the diagnosis and proposed after-version.

## Root ownership belongs to synchronization

An otherwise valid collection with a handwritten root AGENTS.md passes input validation. Writing or repairing its conventions does not require replacing those root instructions. A subsequent `sync --dry-run`, `sync --check`, or actual sync rejects that handwritten index with DOCUMENT_CONFLICT. Preserve it and report pending synchronization until adoption is explicitly resolved. Changing its generator stamp to make the checker pass would falsely claim ownership.
