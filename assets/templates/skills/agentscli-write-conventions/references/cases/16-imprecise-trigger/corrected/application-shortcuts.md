# Application shortcuts

An application keyboard shortcut invokes the same command as its visible menu item. Show the key combination beside that menu item so users can discover the shortcut without trying keys.

Keep application shortcuts inactive while focus is inside an editable text field. A key combination used while editing text must not unexpectedly invoke an application command.

For example, suppose the menu item `Show outline` displays `Alt+O`. Outside an editable text field, `Alt+O` invokes the same command as selecting `Show outline`. While an editable text field has focus, the application shortcut does not run. This agreement covers application shortcuts, rather than operating-system shortcuts or normal text entry.
